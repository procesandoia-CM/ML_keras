🎯 El Problema y El Objetivo

Problema: Enseñar a una computadora a reconocer gestos humanos de forma visual no es trivial. Requiere procesar variaciones complejas en iluminación, ángulos y formas de las manos en tiempo real.

Objetivo: Construir un modelo de Deep Learning capaz de clasificar imágenes en tres categorías (Piedra, Papel o Tijera), demostrando el poder de las Redes Neuronales Convolucionales (CNN) en el campo de la Visión por Computadora.

⚙️ El Ciclo de Vida del Modelo

1. Recolección

Captura de datos mediante imágenes de gestos desde múltiples ángulos para crear un dataset robusto.

2. Entrenamiento

Uso de TensorFlow y Keras (Deep Learning) para extraer patrones visuales de las imágenes.

3. Evaluación

Pruebas de validación para garantizar un alto porcentaje de confianza en la predicción.

4. Despliegue

Creación de una interfaz interactiva con Streamlit Cloud para consumo del usuario final.
